# Наблюдаемый совет. Hyperliquid, без ордеров

Это не бот. `MODE` может быть только `OBSERVE`. Любое другое значение скрипт отвергает на старте. Ордера не собираются и не отправляются.

## Что делает один проход

1. Тянет публичные свечи BTC 1m и стакан Hyperliquid.
2. Сжимает их в снимок: доходности, EMA, VWAP, ATR, ER20, дисбаланс, стены, CVD, спред.
3. Отказывает, если данные старше 1.5 с, нет стакана или нет свечи.
4. Жёсткий гейт до моделей: спред > 3 bps, ER20 < 0.25, ATR > 2.5× среднего.
5. Зовет совет только по триггеру: перекос стакана, |cvd_z| > 2 или пересечение VWAP.
6. Четыре стула параллельно, таймаут 8 с. Нет ключа, битый JSON, ошибка API — WAIT.
7. Кворум 3 из 4, confidence от 0.55, никто против, Claude может наложить VETO.
8. Пишет всё в `events.jsonl`. Поле `order_sent` всегда false.

`shadow_vote` — локальные if-правила. Это не Grok, не Claude и не голос. Они не входят в кворум.

## Запуск на Mac

```bash
cd grok_council
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python3 observe.py --self-test
python3 observe.py --once
python3 observe.py
```

`--once` берёт уже закрытые свечи и не ждёт минуту. CVD в этом режиме пустой: сделки приходят только из вебсокета. Боевой просмотр — без флага, Ctrl+C чтобы остановить.

Ключи в `.env` необязательны. Пустой ключ значит, что стул молчит. Деньги от этого не двигаются.

## Что смотреть в логе

- `skip` / `CHOP` — гейт остановил до совета. Это нормальный исход.
- `vote` — ответ модели.
- `decision` / `would_enter` — что система сказала бы. Не филл.
- `counterfactual` — куда ушла цена через 5, 15 и 30 минут после гипотетического входа.
- `size_preview.binding = LEVERAGE` — потолок плеча, а не риск 0.75%, режет размер. На $400 так и задумано.
