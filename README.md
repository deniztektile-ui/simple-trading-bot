# Simple Trading Bot + Совет ИИ

Учебный торговый бот для BTC/USDT. Работает **только в симуляции** — настоящие деньги не используются,
реальная торговля в этой версии отключена.

## Как он принимает решения

1. Каждые 8 секунд бот берёт свежие цены с Binance (напрямую, без лишних библиотек; ключи биржи не нужны).
2. **Стратегия** — пересечение скользящих средних SMA 5 и SMA 13:
   - быстрая пересекла медленную снизу вверх → сигнал **КУПИТЬ**;
   - сверху вниз → сигнал **ПРОДАТЬ**.
3. **Совет ИИ** — при каждом сигнале бот спрашивает Claude, ChatGPT, Grok и Gemini.
   Каждый отвечает BUY / SELL / HOLD с короткой причиной. Сделка проходит, если большинство ответивших согласно.
4. **Стоп-лосс 0.8% и тейк-профит 1.6%** закрывают позицию автоматически, без совета.
5. Все сделки записываются в `trades.csv`, все ответы ИИ — в `council.log`.

Если ключей ИИ нет — бот торгует только по стратегии (это меняется в `config.py`).

## Смотреть работу бота в браузере

Когда вы запускаете `python bot.py`, сама открывается страница **http://localhost:8000**.
На ней видны цена, капитал, открытая позиция, график с точками покупок и продаж, все сделки,
журнал событий и голоса совета ИИ. Страница обновляется каждые 3 секунды.
Она работает только на вашем компьютере и только пока бот запущен.

## Файлы

| Файл | Что делает |
|---|---|
| `config.py` | Все настройки: монета, свечи, размер позиции, стопы, комиссия, совет ИИ |
| `bot.py` | Запуск бота (симуляция в реальном времени) |
| `dashboard.py` | Страница в браузере: http://localhost:8000 |
| `market_data.py` | Загрузка цен с Binance |
| `strategy.py` | Индикаторы (SMA, RSI) и сигналы |
| `council.py` | Совет ИИ: опрос четырёх моделей и подсчёт голосов |
| `paper_broker.py` | Симулятор счёта: покупка, продажа, комиссии, стопы |
| `backtest.py` | Проверка стратегии на истории |
| `tests/` | Автотесты (работают без интернета) |

## Установка и запуск

```bash
pip install -r requirements.txt
cp .env.example .env        # затем вставьте свои ключи ИИ в .env
python backtest.py --days 7 # сначала проверить на истории
python bot.py               # запустить симуляцию (остановка: Ctrl+C)
python -m pytest -q         # тесты
```

Ключи хранятся только в файле `.env` на вашем компьютере, в GitHub он не попадает.

## Важно: результаты проверки

Проверка на смоделированных ценах (похожих по колебаниям на BTC, 20 прогонов):

| Настройка | Сделок | Результат |
|---|---|---|
| Свечи 1 мин, 3 дня, с комиссией 0.1% | ~185 | **около −30%** |
| То же без комиссии | ~185 | около +0.7% |
| Свечи 1 мин, 15 дней | ~936 | около −84% |
| Свечи 15 мин, стоп 2% / тейк 4%, 15 дней | ~63 | около −11% |

Вывод: на минутных свечах бот делает очень много сделок, и **комиссии съедают баланс**.
Сама стратегия на случайных ценах прибыли не даёт. Реальный рынок может вести себя иначе —
поэтому обязательно запустите `python backtest.py --days 7` на настоящих данных.
Совет ИИ может отсеивать часть плохих сигналов, но это нужно проверять на симуляции, а не на деньгах.

## Безопасность

- **Репозиторий публичный** — его код может видеть любой. Поэтому ключи ИИ пишите **только в файл `.env`**,
  никогда не в `config.py` и не в другие файлы. Файл `.env` в GitHub не попадает (он в `.gitignore`),
  а тест `python -m pytest -q` проверяет, что ключи случайно не попали в код.
- Ключи бирж боту не нужны: торговля только в симуляции, реальные ордера не отправляются.
- Страница `http://localhost:8000` открывается только на вашем компьютере. Другие сайты читать её не могут.
- Если ключ где-то засветился (например, вы отправили его в чат) — удалите его на сайте ИИ и создайте новый.

## Названия моделей ИИ

Указаны в `config.py` → `AI_MODELS`. Если какой-то ИИ отвечает ошибкой «model not found»,
замените название на актуальное с сайта этой компании.

## Исправление частых входов и ограничение потерь

Минутные свечи сохранены. Теперь BUY требует 3 закрытые свечи после пересечения:
цена и быстрая SMA выше медленной SMA, медленная SMA растёт, разрыв средних
не меньше 0.25% и порога покрытия двух комиссий. Это фильтр шума, не обещание прибыли.
SELL при обратном пересечении и защитный стоп сохраняются, даже если сделка убыточна.
Размер позиции по умолчанию уменьшен с 50 до 10 USDT.
После 3 подряд убыточных сделок или потери 2% начального баланса новые входы
останавливаются до перезапуска. Это лимит за запуск, не за календарный день;
перезапуск сбрасывает бумажный счёт и лимиты. Гэп может превысить лимит.
Бэктест применяет тот же фильтр входа и ограничения (без совета ИИ).
После голосования при недоступной свежей цене сделка пропускается.

Эти изменения не устраняют все убытки. Старые сделки по скриншоту нельзя
воспроизвести точно без исходных свечей и журнала. Проверяйте новую версию
на истории и в симуляции; реальные ордера по-прежнему отключены.
